# DevOps-TD3-ci

Comprendre le concept et les avantages de l'intégration continue (CI).
Mettre en place un pipeline de CI simple avec GitHub Actions pour un projet Node.js.
Déployer une application statique avec GitHub Actions vers GitHub Pages.
Simuler un déploiement vers un serveur avec GitHub Actions.
Découvrir la configuration de base de GitLab CI/CD.
Installer et configurer Jenkins avec Docker et le connecter à un dépôt Git.
